# cool-origins

A set of custom origins for the Origins Reborn minecraft plugin.

## Origin List

✅ - Completed  
✴️ - Uses Skript for custom powers

| Origin Name | Description                                                                    | Status |
| ----------- | ------------------------------------------------------------------------------ | ------ |
| Breeze      | A breeze-like being that can manipulate wind to boost themselves into the air. | ✅✴️   |
| Rat         | A rodent that can fit into small spaces and has enhanced senses. Can also poo  | ✅✴️   |

## Project Structure

Each origin is contained within its own folder inside the `origins` directory. Each folder contains all necessary files for that origin, including configuration files and Skript scripts if applicable.

## Installation

Automated install scripts coming soon!

For manual installation, copy the origin json files to your Origins Reborn `origins` folder and any Skript files to your Skript `scripts` folder.
